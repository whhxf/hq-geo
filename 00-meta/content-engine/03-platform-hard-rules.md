# 视频号、抖音、小红书发布硬规则

**采集日期：** 2026-09-09  
**最后核验日期：** 2026-09-09  
**下次复核日期：** 2026-10-09；进入正式发布会话时提前复核  
**规则状态：** 第一版；任何进入 `ready_to_publish` 的内容都必须在发布前重新核验当前官方界面。  
**重要区分：** `硬规则` 来自现行法律、平台规范或当前官方上传界面；`官方建议` 影响推荐但不是上传门槛；`策略偏好` 只能进入创作模式库。

## 1. 跨平台强制规则

### AI 生成内容标识

自 2025-09-01 起施行的《人工智能生成合成内容标识办法》覆盖文本、图片、音频、视频和虚拟场景。用户发布生成合成内容时，应主动声明并使用平台提供的标识功能；不得恶意删除、篡改、伪造或隐匿标识。

系统行为：

- 每个素材记录 `ai_generated`、`ai_edited`、`generation_tool` 和 `human_verified`；
- 发布包中生成 `ai_disclosure_required`；
- 若平台提供 AI 声明开关，发布预检必须要求勾选；
- 不主动擦除模型水印、元数据或平台标识；
- AI 生成的事实、案例、引语和效果必须由人或证据层复核。

### 通用内容底线

三平台均明确禁止或限制：违法内容、虚假误导、侵权、冒充、骚扰、低俗、欺诈、作弊流量、诱导互动、未经允许的站外导流和规避平台审核。具体执行随内容类别、账号资质和商业性质变化。

系统行为：公开发布前必须完成：

1. 事实与来源检查；
2. 肖像、音乐、图片、字体、商标和引用授权检查；
3. 医疗、金融、教育、招商、食品等高风险类别检查；
4. 商业合作、广告和利益关系标识；
5. AI 内容标识；
6. 平台文本、画面、字幕、评论引导和账号资料检查。

## 2. 视频号

### 当前可核验上传规格

来源为视频号官方帮助页“视频号发表视频/图文有什么格式要求？”：

| 项目 | 当前规则 |
|---|---|
| 内容类型 | 支持图文或视频 |
| 图文数量 | 移动端 1—20 张；网页端可上传 18 张，超过 18 张时进入媒体相册逻辑 |
| 图片比例 | 宽高比 0.33—3.0 |
| 图片格式 | 官方页面表述为格式不限，但不支持 GIF |
| 视频时长 | 移动端 3 秒—60 分钟，部分旧手机为 30 分钟；网页端 3 秒—8 小时 |
| 视频大小 | 最大 2GB |
| 视频比例 | 0.33—3.0，推荐标准 16:9 或 9:16 |
| 清晰度 | 推荐 1080P 及以上 |
| 编码/格式 | 页面表述为格式不限；不支持 HDR。iPhone 发布推荐 H.265；Chrome 网页端暂不支持 H.265 |

### 硬性内容约束

《微信视频号运营规范》要求：

- 账号资料真实、客观、可信，不得过度营销或误导；
- 不得使用未经允许的外挂、第三方工具或规避审核；
- 不得通过奖励、强迫等方式诱导分享、关注、点赞和评论；
- 不得制造虚假流量；
- 广告应符合法律并具有可识别性；
- 不得标题夸张且与内容严重不符；
- 不得编造或夸大猎奇、暴富、成功故事；
- 对 AI、深度学习、VR 等生成或非真实音视频及剧情演绎，平台可依法要求显著或隐式标识。

### 官方推荐建议，不是硬门槛

官方帮助页“视频号作品如何获得更多推荐流量？”建议：

- 原创、人格化、高价值；
- 画质清晰，使用恰当音乐，必要时加配音和字幕；
- 重视封面、标题和开头 10 秒；
- 赛道统一、风格明确，最好真人出镜；
- 稳定更新；
- 关注热点并发表观点；
- 回复评论；
- 在标题和文案使用精准关键词；
- 参与热门活动和话题；
- 用单篇作品数据查看完播率、互动率和作品诊断。

这些建议可以进入视频号策略权重，但不得写成“违反就不能发布”。

## 3. 抖音

### 当前已确认的内容规则

《抖音社区自律公约》要求或明确不鼓励：

- 不得侵权、冒充、虚假误导、伪造身份或数据；
- 不得发布未经平台许可的广告、商业招揽、过度营销或站外引流；
- 不得批量发布同质、低质、无意义内容；
- 不得通过不当方式诱导关注、点赞、评论；
- 避免搬运、第三方水印、抄袭创意和文案；
- 避免画质差、内容不完整、标题耸动；
- 鼓励原创、清晰、完整、可观看、有实质内容；
- 官方建议真人出镜或讲解，避免虚假做作、卖惨博眼球和虚假人设；
- 科学类信息应有科学依据，文字应正确规范。

抖音开放平台针对挂载小程序短视频的管理规范还明确要求：数据、统计和引用真实准确；旁白、字幕与画面不得故意矛盾；不得用后期效果伪造结果；不得使用绝对化广告用语；不得简单拼接、无关音画、机械配音、单图堆字或只改封面/BGM 重复发布。该文件只直接适用于“挂载小程序短视频”，系统只能把它作为商业/挂载内容的硬规则，以及普通创作的高可信风险提示。

### 尚未确认的上传规格

当前抖音创作者中心需要登录，本轮没有取得现行网页上传界面的时长、大小、比例和格式提示。抖音开放平台旧 API 文档提供过 4GB、分片上传和特定格式建议，但页面明确停止更新于 2022-09-06，因此不得作为 2026 年普通创作者发布的硬规则。

系统行为：

- 抖音发布包在当前 UI 规则未核验前只能标为 `prepared`，不能标为 `ready_to_publish`；
- 发布会话开始时登录创作者中心，读取当前上传控件提示；
- 把当前时长、大小、比例、编码、标题与正文限制保存为带日期快照；
- 实际素材用当前快照校验；旧 API 限制只作为兼容性参考。

## 4. 小红书

### 当前官方创作平台上传规格

本轮在已登录的小红书创作服务平台当前页面核验：

| 项目 | 当前规则/提示 |
|---|---|
| 视频时长 | 不超过 4 小时 |
| 视频大小 | 不超过 20GB |
| 视频格式 | 支持常见格式，推荐 MP4、MOV；上传控件接受 `.mp4 .mov .flv .f4v .mkv .rm .rmvb .m4v .mpg .mpeg .ts` |
| 视频清晰度 | 网页上传大于 1080P 可获得更清晰画质 |
| 单张图片大小 | 不超过 32MB |
| 图片格式 | 推荐 PNG、JPG、JPEG、WEBP；控件接受 `.jpg .jpeg .png .webp` |
| 动图 | 不支持 GIF、Live Photo 或由 Live Photo 转换的图片 |
| 图片比例 | 页面称无硬性比例限制，推荐 3:4—2:1 |
| 图片分辨率 | 推荐不低于 720×960；网页上传大于 1280P 可获得更清晰画质 |

标题、正文和话题数量限制尚未在不创建外部草稿的前提下核验，发布前必须从当前编辑界面读取。

### 社区硬性内容约束

《小红书社区规范》要求：

- 不得虚假宣传、虚假交易、价格欺诈、侵权或营销高风险品类；
- 不得在内容中留电话、微信、邮箱、地址等个人联系方式；
- 不得发布其他平台网址、二维码或水印；
- 不得使用惊悚封面、标题党或内容不符；
- 分享的产品与内容应相关，并来自真实体验，避免照搬商家指令或大量官方宣传语言；
- 不得散布虚假信息或伪科学；
- 不得用机器、脚本、高频批量发布或其他方式伪造数据。

### 商业内容附加约束

小红书蒲公英商业合作内容审核规范不允许明示或暗示超越常识的保证，如“完全有效、没有副作用、人人适用、100% 有效、零风险”等。健康、食品等类别有额外限制。只有内容属于商业合作或相应品类时，才加载对应规则集。

### AI 内容

小红书生成式人工智能服务协议说明输出具有不确定性，用户应核验真实性、准确性和可靠性；平台会对生成内容作显著标识，用户不得删除、篡改、伪造或隐匿相关标识。

## 5. 发布状态机

```text
draft
  → researched
  → canonical_ready
  → platform_rendered
  → assets_ready
  → rules_checked
  → prepared
  → ready_to_publish
  → awaiting_human_authorization
  → published
```

阻止进入 `ready_to_publish` 的条件：

- 任何平台当前上传规则未知或已过复核期；
- 有未核实事实、未获授权素材或高风险声明；
- AI 内容需要标识但发布包没有声明；
- 平台变体缺少必需字段或素材；
- 文案承诺与内容、画面或证据不一致；
- 目标账号未登录或权限不明确。

## 6. 规则维护

每条规则必须保存：

```yaml
rule_id: xhs.image.max_bytes
platform: xhs
scope: organic_image_post
type: hard_limit | prohibited | disclosure | official_recommendation
value: 33554432
unit: bytes
source_url: ...
verified_at: 2026-09-09
review_after: 2026-10-09
status: verified | scoped | stale | unknown
notes: ...
```

复核频率：

- 上传规格和编辑字段：每月，且每次正式发布前运行时复核；
- 社区规范：每季度或平台公告变更时；
- 法律与 AI 标识：每季度或监管更新时；
- 官方推荐建议：每季度，只影响策略权重，不阻止发布。
