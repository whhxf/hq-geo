# Image Appeal

图文吸引力。**这条线管「有人愿意点」，排版线管「读得下去」，图片线管「有没有骗人」。**

三件事各管各的，不重叠。判据真源在 `rules/appeal-rules.json`（十四条，AP-01 至 AP-14）。

---

## 为什么会有这个能力

2026-10-08 之前，图片线五站全是事实纪律——每一站都在回答「这张图有没有骗人」，
没有一站回答「有没有人愿意看」。于是出现了一件事：

1. 十张卡片交付，四项吸引力复核全填 `pass`；
2. Conan 看完说「图都比较素啊，看起来让人没啥阅读兴趣」。

**复核登记了，质量没守住。** 两个原因叠在一起：

- **机器那一半是空的。** 「素」当时只是一句审美意见，没有判据，也没有数字。
- **人那一半被写的人自己填了。** 写简报的 Agent 自己判「有没有人愿意看」，
  而它在这一点上没有判据——它把 `scannable_in_feed` 的 pass 读成了「有吸引力」。

这个能力补的就是这两半。

## 两半分工

| | 机器判 | 人判 |
|---|---|---|
| 判什么 | 能数出来的：字数、色数、边缘密度、风格一致性、序号、要点条数 | 数不出来的：好奇心、猎奇、情绪价值、信息价值、社交货币 |
| 谁执行 | `scripts/check_appeal.py` | 复核人，登记进简报的 `appeal_review` |
| 判据来源 | `rules/appeal-rules.json` 的 `checkable: machine` | 同文件的 `checkable: human`（AP-10 至 AP-14） |
| 怎么算过 | 硬边界内（`fail` 拦），目标范围内（`warn` 不拦） | 九项全 `pass`，且 `reviewed_by` 不是 `author` |

**两半都要，不能互相替代。** 只跑校验器，会交付一批合规但没人点的图；
只靠人看，人看十次就会开始照模板填。

## 实测：把「素」变成数字

2026-10-08，对**被否的十张卡**和**一张有视觉承载体的真实截图**跑了同一套量法。

| 指标 | 意思 | 被否的十张卡 | 有承载体的图 |
|---|---|---|---|
| `distinct_colors` | 4 位/通道量化后还剩几种颜色 | 59–63 | 322 |
| `edge_density` | 相邻像素亮度差 > 24 的比例 | 0.028–0.047 | 0.067 |
| `dominant_luma_ratio` | 最大明度带占多大 | 0.948–0.968 | 0.896 |

**两组区间不重叠。** 阈值取间隙里的整数：色数 100，边缘密度 0.05。

主色占比 0.96 的意思很直接：**整张画面 96% 是同一个明度**——只有底色的抗锯齿渐变。
整张图只有一个视觉事件，就是那几行字。

量法写死在 `scripts/measure_card.py`：

- **4 位/通道量化**，不是原始色数。抗锯齿的过渡色会撑出上千种颜色，
  那不是视觉事件，是渲染噪声。
- **2 像素步长抽样**。1080×1440 全采样在纯 Python 里要几秒；步长 2 与全采样差异小于 1%，
  而判据的阈值是 0.05 这种量级。
- **确定性**。整数亮度、固定步长、固定量化，同输入同输出。

**阈值还没校准。** 样本是 10 比 1，`AP-03.value.calibrated` 是 `false`。
现在能说明的只有「明显偏素」。跑够 3–5 套真实图集再回来收紧。

## 按项目适配风格

风格靠看，不靠读——**这里不做自动选择**（宪法 7）。脚本只提供筛选用的字段。

风格库（`capabilities/image-production/styles/image-styles.json`）里每套风格都写了
`carrier`，它决定封面靠什么承载视觉：

| `carrier` | 套数 | 封面要什么 | 判据 |
|---|---|---|---|
| `base_image` | 13 | 必须有 `base_image` | AP-02 |
| `typography` | 1（`black-gold-manifesto`） | 不要底图，靠与内页的底色差异隔离 | AP-04 |

**这条接线是 2026-10-08 补的，因为它正好解释了那次事故**：简报选了
`editorial-minimal`——它的样张是一张俯拍静物照，`carrier` 是 `base_image`——
实际交付的是米白底加居中文字，一张底图都没有。以前没有任何字段能发现这个错。

## 目录

| 文件 | 作用 |
|---|---|
| `rules/appeal-rules.json` | 判据真源。十四条，每条带数值、来源、证据等级、采集日期 |
| `methods/expert-playbook.md` | 专家方法论。五个心理触发器 + 序列与记忆 + 反面清单，每个来源带链接 |
| `scripts/measure_card.py` | 量视觉复杂度。只测量，不判断 |
| `scripts/check_appeal.py` | 执行机器判据。阈值从规则文件读 |
| `tests/test_appeal.py` | 单测：测量的判别力与确定性、十四条的正反例、规则真源 |

入口在 `skills/image-pipeline/SKILL.md`。契约是
`capabilities/image-production/contracts/image-brief.schema.json`。

**零第三方依赖。** PNG 解码复用图片线的 `png_io.py`，机器化模式的词表复用文章线的
`check_authorial.py`——**都靠 import，不复制**。一个方法只保留一个真源。

## 证据等级

规则里的来源分六档（定义见 `rules/appeal-rules.json` 的 `evidence_tiers`）。
这份文件里最重要的是这两档的区分：

- **直接证据** —— 我们自己对这个产物的实测。有原始数字和量法。AP-03 是这一类。
- **强代理证据** —— 同行评审的实证研究，测的是同一个心理机制，但被测对象不是我们的产物。
  Loewenstein 1994、Berger & Milkman 2012、Kivetz 2006、Von Restorff 1933 都是这一类。

**代理证据支持机制，不支持效果承诺。** 「高唤醒促进分享」是一个被验证过的机制；
「照这个做，转发翻倍」不是，任何产物里都不许写后者。

## 这个能力不能做什么

- **不能保证效果。** 十四条判据里没有一条能预测点击量。
- **不能替人判那五项。** 它只守「该判的时候有没有人判过、判的人是不是独立于写的人」。
- **不能自动选风格。** 给候选，人做选择。
- **不能判「配不配得上那句话」。** 图和文字对不对得上，仍然归人。
