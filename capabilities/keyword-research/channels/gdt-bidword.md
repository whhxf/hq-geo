# 腾讯广告 · 竞价关键词工具

**2026-09-29 跑通。** 用 `AI数字员工` 做了一次完整拓词，196 条结果。

它是**异步作业**模型，和聚光的即时页签完全不同：

```
填种子词 → 提交拓词任务 → 等（本次约 3 分钟）→ 状态「成功」→ 下载 CSV
```

## 能拿到什么

导出 CSV（UTF-8 带 BOM），一行一个词：

| CSV 列 | 记录字段 | 口径 |
|---|---|---|
| 关键词 | `keyword` | |
| 流量类型 | `traffic_type` | 本次全是「搜一搜」。导出是**按版位分文件**的 |
| 推荐理由 | `reason` | 平台标记，见下 |
| 月均搜索量 | `monthly_search_index` | **平台自有口径**。平台叫「月均搜索量」，聚光叫「月搜索指数」——同一个槽位，不同名字，**不跨平台比较** |
| 月均点击量 | `monthly_click_index` | 平台自有口径。大量为 `<5` |
| 竞争程度 | `competition` | **数字**（本次只出现 1、2），不是「高/中/低」。标度上限未核实 |
| 指导价 | `bid_cny` | **本次 196 条全为空**。这个版位不给出价 |

`推荐理由` 的平台标记是聚光没有的，而且有用：

| 值 | 意思 |
|---|---|
| `飙升词` | 搜索量在涨 |
| `蓝海词` | 平台认为竞争小、有机会 |
| `高跑量词` | 平台认为能吃量 |
| `-` | 无标记 |

## 口径限制（硬线）

1. **搜一搜 ≠ 微信生态 ≠ 视频号。** 它覆盖的是微信内搜索（公众号、小程序、视频号等内容）。
   比微信指数精确得多——微信指数测的是整个微信生态的热度，是 `proxy`；
   这个是搜索广告工具直接返回的，是 `official_commercial`。**但两者都不是「视频号搜索量」。**
2. **量级比小红书小一个数量级。** 同一个词 2026-09-29 的对照：
   `AI数字员工` 在搜一搜 **40**，在小红书聚光 **370**。**跨平台不比较，但差异本身是信息**——
   它说明这个需求在微信生态里比在小红书里弱得多。
3. **导出按版位分文件，不是一个文件装所有版位。** 文件名带版位名（如 `64883507-搜一搜(...).csv`）。
   拿到的数据只代表那个版位。
4. **不做映射**：竞争程度聚光给「高/中/低」，广点通给 1、2。
   把 1 翻译成「低」是编，把「高」翻译成 3 也是编——**两个标度不可比，各自只在本平台内有效**。
   和月均搜索量一样，跨平台只能看出「哪个更强」，看不出「差几倍」。
5. **平台会返回大量词面变体，那不是需求拓展。** 见「已知陷阱」。

## 采集步骤

1. 用 `ego-browser` 开本机 Chrome（登录态）。
2. 打开 `https://ad.qq.com/atlas/<账户ID>/tool/bidword`。`<账户ID>` 是广告账户号，**不写进系统层**。
3. 在「新增种子词」填词，回车新增。**上限 1000 个**（单个词 20 字）——可以批量。
   **一次填一个词**：`page.fill(input[class*=seedWord] >> nth=<最后一个>, 词)` 再 `page.press(..., "Enter")`，
   回车后平台会自动追加一个空行。**不要用 `keyboard.paste`**，见「已知陷阱」。
   空行不影响提交（实测 7 行里 2 行空的，提交后种子词列表只有 5 个）。
4. 按需设「地域词」「不包含词」（上限 100）、结果设置（不包含已购词 / 包含非地域词）。
5. 选「适用投放版位」：`搜一搜` / `QQ浏览器`。**一次一个版位，分开落盘。**
6. 点「提交拓词任务」。**这是异步的**——任务进「拓词任务」表，状态从「处理中」变「成功」。
7. 状态变「成功」后点「下载」。**文件有效期 7 天**，过期要重新提交任务。
8. **拿到 CSV 立刻转成 `research-record` JSON 落盘。** 别指望回头再下——7 天后链接就没了。

**落盘到 `research/raw/<date>-gdt-bidword-<版位>-<slug>.json`，原始 CSV 一并留在同目录作对照。**

## 已知陷阱

- **196 条里 181 条（92%）是 `<5`。** 词多不等于有量。看「多少条」会被骗，
  要看**有真实数字的有几条**——本次只有 15 条。
- **大部分结果是词面穷举，不是需求拓展。** 196 条归一化（去大小写/空格）后是 138 个词面，
  但绝大多数是同一件事的写法差异：`AI数字员工` / `ai数字员工` / `Ai数字员工` / `AI 数字员工` /
  `aI数字员工` / `#Ai数字员工` / `AI智能數字員工`（繁体）/ `ai数字员工pingtai`（拼音）。
  **平台在按字符变体穷举。** 这一层要自己去重，别当成 196 个不同需求。
  **去重跑 `_normalize_surface()`（`scripts/validate_research.py`）**，别手工合。
  2026-09-29 实测：132 条 → **97 个词形**（压缩 26.5%），21 个组被正确合并。
  **这次实测还抓出规则自己的一个缺口**——平台把 `#AI数字员工` 当成独立词返回，
  而旧规则不去 `#`，一次采集凭空多出三个「不同的词」。已修，见
  `methods/cross-evidence-validation.md` 第三节。
- **噪音形态和聚光完全不同。** 聚光的噪音是「同形不同义」（`geo`、`ai数字人`）；
  广点通的噪音是三类：
  - **地理词**：`深圳AI数字员工`、`福建ai数字员工`、`乌海ai数字员工`、`重庆ai员工`、`佛山ai员工`、`高新区 ai员工`
  - **品牌词**：`用友ai数字员工`、`阿里AI数字员工`、`小冰AI数字员工`、`360ai数字员工`、`中石化AI数字员工`、`华润 AI数字员工`、`DeepSeek ai员工`
  - **乱码/无关**：`Furiosa AI 员工`、`AI 数字财务`、`数字人ai面试`、`AI数字老师`
- **`月均点击量` 全是 `<5`，`指导价` 全空。** 这两个字段在本版位**没有区分度**，
  不要拿它们做判断依据。
- **`飙升词` 标记值得单独看。** 本次 `会展AI数字员工` 被标为飙升词且竞争度 1——
  量是 `<5`，但**趋势信号和量级信号是两件事**。
- **`蓝海词` 标记不能当竞争度的测量值。** 2026-09-29：平台给 `AI数字员工` 标「蓝海词」，
  而同一批数据里它的 `competition` 是 **2**（不是最低的 1）；小红书聚光给同一个词判「高竞争」。
  「蓝海」是**推荐语不是测量值**，而且很可能只是「量小」的另一种说法——
  **不是没人做内容，是没人搜**。真正的内容稀缺要有 SERP 证据（有人搜 + 前排泛化），
  见 `methods/serp-overlap-clustering.md` 第五节。
- **这个渠道给不了词间关系。** 132 条里 66 条含「数字员工」——它是**同一个词的不同说法**，
  不是「相关的不同词」。要做相邻词发现，去聚光（给上下游）或 SERP（给内容池重叠）。
- **不要用 `keyboard.paste` 填种子词。** 2026-09-29 实测：传参 `"ai智能客服"`，
  粘进输入框的是**用户剪贴板里的实际内容**（一段 `sk-` 开头的凭据）——不是实参，也不报错。
  同一个调用在 `about:blank` 上完全正常，所以是**站点相关的剪贴板权限问题**，不是用法错误。
  **填种子词用 `page.fill(selector, 词)` + `page.press(selector, "Enter")`**，一个词一行。
  详见 `AGENTS.md`「联网与平台操作」。
- **平台会改版。** 这个文件写的是 2026-09-29 的界面。下次跑如果对不上，改这个文件，不要改记录格式。
