# 生图能力发现契约

顺序：会话系统工具 → 本地生图 Skill → 问用户。

Agent 提供当前会话工具清单，不能由脚本猜宿主能力。发现输出为调用计划，Agent 读取相应 Skill 后执行。没有候选时输出 `needs_user_input`，不报已生成；失败输出 `failed`，不偷偷切到付费接口。

生产记录保存提供方、发现证据、完整提示词、项目内文件路径、SHA256、synthetic=true 和人工或独立 Agent 复核状态。真实截图不进入生图工具。

本地 Skill 只作为候选：必须检查入口、依赖、凭证是否存在，不输出凭证内容。仅有名称或文档不是可执行能力。
