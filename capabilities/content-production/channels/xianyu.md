# 闲鱼 · 交易渠道契约

闲鱼是**交易渠道**，不是内容渠道。核心是**准确描述商品并促成交易**，不默认加载 AI 搜索排名、
FAQ、Schema、llms.txt 或关键词密度。把内容平台的做法套上来，只会让商品页变成没人看的软文。

## 落盘位置

```text
content/packages/xianyu/<idea-id>/<topic-id>/
```

一个 `<idea>/<topic>` 目录就是一个渠道包。至少要有一份 `copy.md` 才算数（产出统计按此口径计数）。

## 最低交付

| 产物 | 路径 | 必须写清 |
|---|---|---|
| 商品文案 | `copy.md` | 标题、真实卖点、适用对象、内容清单、文件格式、软件版本、交付方式与期限、售后范围 |
| 封面 / 内页简报 | `content/briefs/`（`ImageBrief`） | 真实预览；尺寸按当前发布入口核验；**禁止虚构买家评价和收益** |
| 发布复核记录 | `<idea>/<topic>/review.md` | 事实引用、版权证明、当前类目资格、规则来源与日期、价格、承诺、授权状态 |

事实只能来自事实包（`facts/`）。没有真实商品前不填充占位事实包，不把研究推断写成商品效果承诺。

## 规则状态

**核验入口：** 闲鱼网页版发布页 / App 卖家中心（需登录）。
**本文件只登记「要核验什么」，不把未核验的写成规则。**

| 项 | 状态 | 说明 |
|---|---|---|
| 类目准入（数字商品 / 软件是否可发、是否需资质） | unknown | 上架前必须从当前发布入口核验并留证 |
| 账号资质（个人 / 企业、保证金、类目权限） | unknown | 同上 |
| 标题 / 详情字段限制（字数、违禁词、外链） | unknown | 同上 |
| 图片规格（数量、尺寸、大小、格式） | unknown | 同上 |
| AI 生成内容标识 | unknown | 生成合成内容需主动声明并标识；跨平台强制规则见 `00-meta/content-engine/03-platform-hard-rules.md` §1 |
| 版权链（软件许可、字体、素材） | unknown | 逐一核验；**不能把「原创」等同于「可上架」** |
| 交付与售后规则（自动发货、退款、纠纷） | unknown | 与商品承诺一致 |
| 禁售 / 限售品类 | unknown | 破解、外挂、代注册、侵权资源等一律不做 |

**`review_after` 到期或平台改版后，本表全部退回 unknown，重新核验。**
核验通过前，本渠道的发布包只能标 `prepared`。

## 硬线

1. **未知项阻止 `ready_to_publish`。** 未知不是「大概可以」，是「不许发」。
2. **不虚构。** 销量、收入、评价、用户经验、版权授权一律不得编造；买家与订单只用匿名编号。
3. **不用「售出不退」兜底。** 低价商品的售后不能靠竞品承诺转嫁；每单维护时间计入收益测算。
4. **买家个人信息不进文档。**
5. **不自动发布、不自动改价、不产生广告花费**——这些属外部状态变更，需用户明确授权。

## 与内容渠道的区别（别把两条线混起来）

| | 内容渠道 | 闲鱼（交易渠道） |
|---|---|---|
| 目标 | 让人看到并相信 | 把商品描述准确并促成交易 |
| 产物 | 母内容 + 渠道版本 | 商品发布包 |
| 是否加载 GEO / FAQ / Schema | 社交内容不加载；官网内容才加载 | **不加载** |
| 规则真源 | `00-meta/content-engine/03-platform-hard-rules.md` | 本文件 + 当前发布入口 |
