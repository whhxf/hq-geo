# 创作策略库

**状态：** 已实现（从 `00-meta/content-engine/04-creative-strategy-library.md` 落盘）
**搬运日期：** 2026-09-28
**最后核验日期：** 2026-09-28

这是策略的执行真源。Agent 选模式读这里，`00-meta` 那份只保留研究结论和理论依据。

## 这是什么

带上下文的生成语法，不是模板仓库。每个模式写清楚：什么时候用、需要什么素材、怎么组织、什么时候会失效。

**全部 10 个模式的证据等级都是 `experimental`。** 它们有平台官方建议或传播机制支撑，但没有在本账号实测过。按 `04` 第 8 节的标准，进入 `stable` 还需要「在两个不同主题下有效」和「有失败样本说明边界」。在这之前，系统不得宣称任何模式必然带来流量。

**这不是平台硬规则。** 平台硬规则在 `00-meta/content-engine/03-platform-hard-rules.md`。策略可以被覆盖，规则不能。

## 怎么选

用户可以指定（「用过程日志」「不要钩子感，做观点解释」「沿用上次的 P09」），也可以让系统按平台、目标、受众状态和现有素材筛。

系统筛选顺序：

1. 用 `required_inputs` 过滤——素材不具备的模式直接排除，不允许为了用某个模式去编素材；
2. 用 `platforms` 过滤；
3. 排除近三次任务用过的（避免同质化）；
4. 剩下的按证据等级和新鲜度加权；
5. **把选中的 `strategy_id` 写进任务**，便于复盘。

随机只改变表达路径，不改变事实、观点和合规约束。

## P01 先证据后观点

- **适用：** 用户怀疑、效果可展示、工具或方法类内容
- **平台：** 抖音、小红书、视频号
- **需要的素材：** 可拍摄的结果或过程（没有实物或屏幕演示就不能用）
- **结构：** 结果/实物/屏幕演示 → 发生了什么 → 为什么 → 适用条件 → 最小复现步骤
- **机制：** 降低理解成本；用证据替代承诺
- **禁用：** 证据不可复核、对比条件不一致、后期效果制造假象

## P02 用户原话开场

- **适用：** 评论和搜索中反复出现具体问题
- **平台：** 抖音、小红书
- **需要的素材：** 真实用户提问记录（伪造评论直接违反）
- **结构：** 一句用户原话 → 指出常见误解 → 给出新解释 → 一个可执行改变
- **机制：** 把抽象理论连接到真实场景
- **禁用：** 伪造评论、拿少数极端表达冒充普遍意见

## P03 反常识但可证明

- **适用：** 有与常见做法不同、且能给出论证的判断
- **平台：** 抖音、视频号
- **需要的素材：** 一条本人真实立场 + 支撑它的证据或演示
- **结构：** 常见做法 → 它在何种条件下失效 → 新判断 → 证据/演示 → 边界
- **机制：** 形成观点记忆点
- **禁用：** 为了冲突而反对、绝对化标题、没有兑现

## P04 拆解一个真实案例

- **适用：** 复杂方法、产品设计、商业或内容分析
- **平台：** 视频号、小红书、博客
- **需要的素材：** 一个可公开的真实案例及其决策节点（没有案例就换模式）
- **结构：** 案例结果 → 关键决策节点 → 可见证据 → 可迁移机制 → 不能照搬的部分
- **机制：** 兼顾故事和实用价值
- **禁用：** 把事后解释写成唯一原因、隐去关键条件

## P05 清单与决策树

- **适用：** 用户处于比较、选择、避坑阶段
- **平台：** 小红书、博客
- **需要的素材：** 能区分条件的判断标准
- **结构：** 先说明选择条件 → 3—7 个检查项 → 不同条件对应不同选择 → 一步行动
- **机制：** 易保存，可逐项演示
- **禁用：** 用统一答案掩盖条件差异

## P06 过程日志 / 小实验

- **适用：** 新方法没有大样本结论，但可以公开验证
- **平台：** 抖音、小红书、视频号
- **需要的素材：** 一次真实发生过的过程记录
- **结构：** 假设 → 做法 → 过程 → 结果 → 意外 → 下一次怎么改
- **机制：** 允许「不知道」，同时积累可信经验
- **禁用：** 只展示成功、修改实验口径、把探索写成定论

## P07 误区纠正

- **适用：** 评论里有稳定误解，或错误做法造成明显代价
- **平台：** 小红书、抖音、博客
- **需要的素材：** 误解的原话 + 一个具体反例
- **结构：** 误区原话 → 为什么看起来合理 → 具体反例 → 更准确标准 → 自测
- **机制：** 适合搜索型问题，也能形成讨论
- **禁用：** 树立稻草人、嘲讽受众、科学依据不足

## P08 场景故事转折

- **适用：** 观点需要通过人物、决策和后果被理解
- **平台：** 视频号、抖音
- **需要的素材：** 真实发生的人物与决策（虚构必须标注）
- **结构：** 人物目标 → 冲突 → 错误选择 → 转折 → 结果 → 机制回扣
- **机制：** 提高代入和记忆
- **禁用：** 虚构真实案例却不标注、卖惨、拖延兑现

## P09 一句话观点 + 三层解释

- **适用：** 视频号观点内容、创始人表达、需要建立长期人格的主题
- **平台：** 视频号、博客
- **需要的素材：** 一条本人长期立场
- **结构：** 明确判断 → 现实场景 → 底层机制 → 反例/边界 → 行动
- **机制：** 观点清晰，又不把世界压成口号
- **禁用：** 只有态度、没有场景和证据

## P10 同题三解

- **适用：** 同一问题在不同人群或条件下答案不同
- **平台：** 小红书、博客、视频号
- **需要的素材：** 能真实区分出三类条件的判断依据（凑不出三类就换模式）
- **结构：** 同一问题 → 三类条件 → 三种解法 → 如何判断自己属于哪类
- **机制：** 减少绝对化，天然适合图文卡片和分段视频
- **禁用：** 人为凑三类、分类不能指导行动

## 平台适配速查

| 平台 | 优先目标 | 推荐模式 | 默认表达 |
|---|---|---|---|
| 视频号 | 人格、信任、观点、可讨论性 | P04、P08、P09、P10 | 观点清楚，保留解释与边界 |
| 抖音 | 快速理解、动态证据、完整兑现 | P01、P02、P03、P06、P07 | 第一画面就出现对象、动作或结果 |
| 小红书 | 搜索命中、真实体验、可保存 | P01、P02、P04、P05、P06、P07、P10 | 标题说清对象和收益，正文分段 |
| 博客 | 完整论证、可被引用、可回溯 | P04、P05、P07、P09、P10 | 结论先行，来源可点开 |

平台硬规则见 `00-meta/content-engine/03-platform-hard-rules.md`。

## 新模式怎么进来

进入 `experimental` 前至少满足一种证据：

- 当前平台官方明确建议；
- 同一账号多次实测，且有相对可比的对照；
- 多个独立高质量案例出现同一机制；
- 可信研究支持其心理或传播机制。

进入 `stable` 还需：至少在两个不同主题或账号条件下有效；有失败样本或反例说明边界；能明确说出它改变了什么；不与平台硬规则冲突。

新模式追加到本文件末尾，并写明证据来源和 `reviewed_at`。不要因为「看起来像爆款」就收录。
