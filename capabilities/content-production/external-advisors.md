# 外部顾问

dbs 是装在本机的另一套工具（`~/.claude/skills/dbs-*`）。**它不归这个仓库管，也不是它的部件。**

这份文件只回答一件事：**什么时候可以问它。**

---

## 三条铁律

**1. 不依赖。** dbs 没装、改名、被删、升级后行为变了——hq-geo 必须照常跑完八站。**任何一站都不许「因为调不到 dbs 所以停下」。** 缺料停机（宪法第 5 条）管的是事实缺失，外部顾问不在其列。

**2. 输出是线索，不是依据。** 它的回答**不进任务单据**。要用它的提问角度，就用你自己的话重新想一遍，并说明依据来自哪里。它的结论没有任何证据等级——按 `AGENTS.md` 的事实准入，它连「外部事实」都算不上。

**3. 不搬文本。** dbs 是 CC BY-NC 4.0，虚实传媒是商业主体，**署名也不能商用**。学做法、自己重写，不搬措辞、不搬清单、**不做逐行同义替换**——那是衍生作品，仍然侵权。

## 可以借的

| 站 | 什么时候问 | 问谁 | 只取什么 |
|---|---|---|---|
| 站 1 | 不确定读者到底要完成什么任务 | `dbs-jtbd` | 「他要完成的事」和「他雇这个产品/内容来做什么」的**拆解角度** |
| 站 3 | 「因为 ___」这个理由自己不确定 | `dbs-theory-grounding` | 命题审查的**提问角度**（这个说法有反例吗？在什么条件下不成立？） |
| 站 4 | 不确定开头能不能让陌生人认领 | `dbs-hook` | 开头的**诊断维度**（独立性、悬念、可信度、与正文的兑现关系） |
| 站 5 | 不确定标题和正文能不能让人读下去 | `dbs-spread`、`dbs-resonate` | 共鸣机制、受众情绪、**传播动机**的提问角度；完播与流失的诊断维度 |
| 站 6 | 怀疑某段论证形式有问题 | `dbs-deconstruct` | 伪概念检测、把「问题」和「话题」分开 |

五站之外不借。**不是因为别的 skill 不好，是因为八站里没有它们的位置。**

**这份清单要覆盖两类需求，缺一类就偏。** 站 1、3、6 是**防错**（别写偏、别自说自话、别堆伪概念），
站 4、5 是**求好**（开头留不留得住人、标题点不点得进去）。只登记防错类，流水线会变成一条
「挑不出错但没人读」的生产线——这是 2026-09-28 那次真实生产暴露出来的偏差。

## 不许用的

**`dbs-content-system` 不得在 hq-geo 目录下运行。**

它的 `tools/init-content-system.js` 里有两段写法，一段有守卫、一段没有：

```js
if (!fs.existsSync(filePath)) { fs.writeFileSync(filePath, content); }  // 业务文件：有守卫

for (const name of ["AGENTS.md", "CLAUDE.md", "README.md", "SOURCE_OF_TRUTH.md"]) {
  fs.copyFileSync(src, dst);   // 根文件：无守卫，直接覆盖
}
```

跑一次就会**静默覆盖 `AGENTS.md` 和 `CLAUDE.md`**——这个仓库的两份宪法文件。

不是它的缺陷，它的目标场景是**空目录**，那里没有文件要保护。是这里不该用它。

它还有第二层问题：那套「内容单元 / 主题地图」是**另一套内容方法论**，和八站并列。混用会产生两个真源，Agent 读哪个都能自圆其说。**一个项目只能有一套内容宪法。**

**`dbs-xhs-title` 的公式库不能搬。** 75 条公式来自第三方 PDF 的二手汇编，无来源、无核验日期，且可能受汇编作品保护。要公式就自己从平台官方规则和真实数据里建，每条带来源。

**`dbs-content-risk-check` 的词表不存在。** 公开仓库做过私有来源剥离，只有判断框架没有词条。我们要词表就按平台官方规则自建，每条记来源 URL 和采集日期。

## 怎么用

**触发条件是「你拿不准」，不是「流程要求」。**

调用是可选动作，不是流水线的一站。判断标准只有一条：

> 这一站你拿不准，**且**它的提问角度能帮你把问题问清楚。

问了之后：把它的提问角度用在自己的判断上，结论写自己的话。**任务单据里不许出现「dbs 说……」**——单据记的是你的判断，不是外部工具的判断。

---

## 为什么不做成依赖

三个事实决定了它只能是「顾问」不能是「部件」：

1. **它零代码。** 33 个 skill 里创作技巧类（`dbs-hook`、`dbs-xhs-title`、`dbs-resonate`、`dbs-script-flow`、`dbs-content`、`dbs-content-risk-check`）**全部 0 个代码文件**。它们是给模型看的说明书，没有 API 可以调——「集成」没有对象。
2. **它不受控。** 它有自己的更新节奏（`/dbs-update`），本机装的版本和上游已经不一致。焊进流水线等于把别人的发版节奏变成自己的风险。
3. **授权不允许。** 见铁律 3。

**它现在的形态就是最好的形态**：全局可用，hq-geo 不依赖它，它也不知道 hq-geo 存在——和 `ego-browser` 一样。
